# Сервер ANDO AUTO: всё на одном сервере

Один сервер держит сайт, мини-приложение для Telegram и MAX, приём заявок, бота объявлений и очередь роликов.

| Адрес | Что там |
|---|---|
| `https://домен` | сайт; заявки с формы — менеджеру в Telegram и в журнал на сервере |
| `https://app.домен` | мини-приложение, каталог и фото машин |
| `https://домен/app/` | тот же каталог в браузере — на него ведут карточки с сайта |

## Что купить

1. **Сервер (VPS) в России**: Ubuntu 24.04, 1 ядро, 1–2 ГБ памяти, от 10 ГБ диска, публичный IPv4.
   Подойдёт самый дешёвый тариф у Timeweb Cloud, Selectel, REG.RU, Beget и т. п. — примерно 200–400 ₽ в месяц.
   Дата-центр — в России: в заявках телефоны, это требование 152-ФЗ.
2. **Домен** `.ru` на себя или на ИП — примерно 200–900 ₽ в год (REG.RU, RU-CENTER и т. п.).

## Установка — одна команда

Откройте консоль сервера (в панели хостинга есть кнопка «Консоль») и вставьте:

```
curl -fsSL https://raw.githubusercontent.com/k9nny/CalculatorV1/claude/eager-gates-snjxp1/deploy/install.sh -o install.sh && sudo bash install.sh
```

Скрипт спросит домен, токен бота и id в Telegram. Токен вводится только здесь, в консоли сервера, —
не присылайте его в чаты. Чего пока нет — пропустите Enter, впишете потом в `/etc/ando/ando.env`.

В конце скрипт покажет IP сервера. У регистратора домена добавьте три A-записи на этот IP: `@`, `www`, `app`.
Через 5–30 минут сайт и приложение откроются по HTTPS — сертификаты сервер получит сам.

## Как это обслуживается

- **Обновления** приходят сами: каждые 5 минут сервер проверяет ветку в GitHub и перезапускается, если код изменился.
  Каталог, фото, заявки и ролики лежат отдельно в `/var/lib/ando` и при обновлении не трогаются.
- Поменять настройки: `sudo nano /etc/ando/ando.env`, затем `sudo systemctl restart ando`.
- Журнал: `journalctl -u ando -f`.
- Заявки: `/var/lib/ando/private/leads.jsonl` (доступ только у root и службы).
- Резервная копия всего, что не восстановится из GitHub: папки `/var/lib/ando` и `/etc/ando`.

Обновление из GitHub значит: всё, что попадает в ветку `claude/eager-gates-snjxp1`, через 5 минут работает
на сервере. Доступ на запись в репозиторий — только у тех, кому вы доверяете сервер.

## Админка на сайте

Добавлять и убирать машины, менять цену и статус, смотреть заявки — из браузера, без Telegram.

    curl -fsSL raw.githubusercontent.com/k9nny/CalculatorV1/gh-pages/a -o a && bash a

Скрипт спросит пароль (от 10 символов) и покажет секретную ссылку вида `https://andoavto.ru/app/<24 случайных символа>/`.

- Ссылка создаётся на сервере и хранится только там (`/var/lib/ando/private/admin.json`), в репозитории её нет. По любому другому адресу — обычный 404.
- Пароль задаётся только на сервере: страницы «создать пароль» в браузере нет.
- 8 неверных паролей с одного адреса — пауза 15 минут; 30 со всех адресов за час — вход закрыт на час.
- Сессия — cookie HttpOnly, SameSite=Strict, Secure; запросы с чужих сайтов отклоняются; страница не индексируется и не открывается во фрейме.
- Фото принимаются только JPEG, PNG и WebP до 15 МБ, тип проверяется по содержимому. В браузере фото уменьшаются до 1600 px, геометка из файла не уходит.

`bash a --show` — показать ссылку, `bash a --new-link` — новая ссылка (старая и все входы перестают работать), `bash a` — сменить пароль.

## Если сервер не видит Telegram

Бесплатный посредник на Cloudflare Workers: код — `deploy/cf-worker.js`, подключение — `bash t`
(`curl -fsSL raw.githubusercontent.com/k9nny/CalculatorV1/gh-pages/t -o t && bash t`).
Проверить, видит ли сервер Cloudflare: `bash t --check`. Платный вариант — свой посредник за границей, `deploy/tg-relay.sh`.
