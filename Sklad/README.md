# Склад и дозаказ

Одна страница `index.html`, которая открывается в любом браузере (Chrome, Edge, Яндекс). Её не нужно устанавливать. Нужен только интернет, чтобы подгрузить модуль для чтения Excel.

## Что она делает

1. **Приёмка.** Вводите артикул и количество или сканируете штрихкод (сканер сам нажимает Enter). Можно загрузить накладную из Excel или CSV. Одинаковые артикулы складываются. Потом нажимаете:
   - «Добавить на склад», если пришла поставка;
   - «Это полный пересчёт — заменить склад», если вы пересчитали весь склад.
2. **Склад.** Остатки по каждому артикулу. Их можно искать, исправлять вручную и скачивать в Excel. Все действия пишутся в журнал.
3. **Заказы и дозаказ.** Загружаете выгрузку заказов (можно несколько файлов сразу). Программа складывает одинаковые артикулы, сравнивает их со складом и показывает, чего не хватает. Список «Докупить» можно скачать в Excel для ТЦ Москва или скопировать. Когда заказ собран, нажмите «Списать заказ со склада».

## Почему артикулы совпадают, даже если записаны по-разному

Во вкладке «Настройки» включены правила (каждое можно выключить):

- русские и английские буквы-двойники считаются одинаковыми: `АВ-12` (русские) = `AB-12` (английские);
- нули в начале не учитываются: `00123` = `123` (Excel часто их убирает);
- пробелы, дефисы, точки и слэши не учитываются: `AB-123` = `AB 123` = `AB123`;
- большие и маленькие буквы не различаются.

Там же есть поле «Проверить артикул», в котором видно, как программа читает артикул.

Колонки в файле программа находит сама по заголовкам («Артикул», «Артикул продавца», «Кол-во», «Количество», «Наименование»…). Если не угадала, их можно выбрать вручную в окне загрузки. Если в выгрузке нет колонки количества (одна строка = одна штука), выберите «Нет колонки — каждая строка = 1 шт.».

Excel-файлы читаются так, чтобы нули в начале не терялись и длинные номера не превращались в `4,6E+12`. В скачанных файлах артикулы тоже записаны как текст.

## Где хранятся данные

- Если открыть страницу по ссылке claude.ai, данные хранятся вместе со страницей и видны на любом вашем устройстве.
- Если открыть файл `index.html` с компьютера, данные хранятся в этом браузере. Если очистить историю браузера, они пропадут, поэтому иногда скачивайте остатки в Excel.

Формат 1С `.mxl` не читается. В 1С сохраните таблицу как Excel (`.xlsx`).
