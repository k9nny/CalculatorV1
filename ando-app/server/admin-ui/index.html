Telegram-бот

Сервер в России не видит Telegram напрямую, поэтому бот работает через посредника на Cloudflare. Вставьте его адрес, токен бота и свой Telegram id — сервер проверит связь и запустит бота.

Добавьте бота администратором канала с правом публикации. Пустое поле отключает отправку постов в Telegram.

Нейросеть Kimi

Разбирает объявления со сленгом и сокращениями, по фото определяет марку и модель, если их нет в тексте. Ничего не додумывает: чего нет в тексте — поле пустое.

Ключ не с platform.moonshot.ai?

Например, у OpenRouter — https://openrouter.ai/api/v1. Пусто — сервер попробует адреса Kimi сам.
