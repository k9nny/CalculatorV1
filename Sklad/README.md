# Склад и дозаказ

Одна страница `index.html`, которая открывается в любом браузере (Chrome, Edge, Яндекс). Её не нужно устанавливать. Нужен интернет: страница подгружает модули для чтения Excel и PDF.

## Рабочий день

1. **День.** Утром вы загружаете лист подбора Озона (PDF) или выгрузку отправлений из Excel.
   - Лист на 1600 с лишним отправлений читается полностью, прочитанное сверяется с цифрой «Количество отправлений» в шапке листа.
   - Товар со склада сначала отдаётся отправлениям с прошлых дней, потом новым.
   - У каждого отправления есть статус: «к сборке», «ждёт мешок» или «не хватает».
2. **Закупка.** Недостающее показано по павильонам (первая часть артикула), внутри — по моделям с разбивкой по размерам.
   - Можно заказать больше (целый мешок) и добавить размеры, которых нет в заказах.
   - Видна сумма закупки по каждому павильону и всего.
   - У павильона, для которого записан номер поставщика, есть кнопка «WhatsApp». Она открывает чат с этим поставщиком, где уже вписан заказ, и ставит отметку «отправлено».
   - Кнопка «Оформить закупку» сразу списывает со склада товар под отправления. Недостающие отправления после неё ждут мешок.
3. **Приёмка.** Мешок считают по факту: у каждой модели есть фото из листа подбора и кнопки «−» и «+» у размеров.
   - Шубу не из заказа можно отправить на склад или вернуть поставщику.
   - Товар сначала раскладывается по ждущим отправлениям, остаток идёт на склад.
   - Расхождения с заказом сохраняются.
4. **Склад.** Остатки по моделям и размерам, залежавшиеся размеры подсвечены.
   - Пересчёт со сканером или вручную. Перед полной заменой склада программа показывает расхождения (недостача и излишек) и даёт скачать их в Excel.
   - Там же список «вернуть поставщикам» и журнал операций.
5. **Анализ.** Считается по истории продаж: по каждому загруженному листу подбора или по выгрузке заказов из Озона (кнопка «Загрузить историю продаж», отменённые заказы не учитываются).
   - Сколько продаётся в день каждой модели и размера.
   - **Закупить впрок** на выбранное число дней, одной кнопкой в закупку.
   - **Залежалось — снизить цену**: давно без продаж, или по истории не было ни одной продажи.
   - **Продаётся хорошо, а на складе нет — можно поднять цену.**
   - **Размеры на складе**: на сколько дней хватит каждого размера.
   - **Поставщики**: как часто не довозят и привозят чужое.

Параметры анализа меняются прямо на вкладке: на сколько дней закупать впрок, сколько дней едет мешок, за сколько дней считать продажи, после скольких дней товар считается залежавшимся.

## Как читается артикул

`A04-LM9-Ser-1900-3XL`: павильон `A04`, модель `LM9-Ser-1900`, размер `3XL`, закупочная цена `1900`.

- Павильон, записанный русской или английской буквой (`А04` / `A04`), считается одним.
- Павильон вида `А-27-…` читается как `А-27`.
- Цену из артикула можно выключить в «Настройках», если это число означает что-то другое.

Артикулы сравниваются по правилам (каждое можно выключить):

- русские и английские буквы-двойники одинаковы;
- нули в начале не учитываются: `00123` = `123`;
- пробелы, дефисы, точки и слэши не учитываются;
- большие и маленькие буквы не различаются.

## Данные

- Если открыть страницу по ссылке claude.ai, данные хранятся вместе со страницей и видны на любом вашем устройстве. Если открыть файл `index.html` с компьютера, данные хранятся в этом браузере.
- **Резервная копия.** «Настройки» → «Данные» → «Скачать резервную копию» сохраняет всё в один файл. «Восстановить из копии» загружает его обратно.
- **Старые записи** удаляются сами: проведённые закупки старше 90 дней, служебный журнал старше 45 дней, история продаж старше 400 дней.
- **Служебный журнал** для разбора проблем: ошибки, загрузки файлов, операции с цифрами, устройство, скорость работы. Последние записи видны в «Настройках».

Формат 1С `.mxl` не читается. В 1С сохраните таблицу как Excel (`.xlsx`).
