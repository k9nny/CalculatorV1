# Склад и дозаказ

Одна страница `index.html`, которая открывается в любом браузере (Chrome, Edge, Яндекс). Её не нужно устанавливать. Нужен только интернет, чтобы подгрузить модули для чтения Excel и PDF.

## Рабочий день

1. **День.** Утром загружаете лист подбора Озона (PDF) или выгрузку отправлений из Excel. Программа раздаёт товар со склада: сначала отправлениям, которые ждут с прошлых дней, потом новым. У каждого отправления есть статус: «к сборке», «со склада», «ждёт мешок», «не хватает». Если отправление уже есть в программе, оно не задвоится. Для листа подбора программа сверяет, сколько отправлений прочитано, с цифрой «Количество отправлений» в шапке листа.
2. **Закупка.** Всё, чего не хватает, разбито по павильонам (первая часть артикула, например `A04`), внутри — по моделям с сеткой размеров. В поле «Заказать» можно вписать больше, на целый мешок, и добавить размеры, которых нет в заказах. Список копируется для WhatsApp или скачивается в Excel. Когда нажимаете «Оформить закупку»:
   - товар со склада сразу списывается под отправления;
   - недостающие отправления получают статус «ждёт мешок»;
   - заказанное сверх отправлений помечается как «едет на склад».
3. **Приёмка.** Открываете приехавшую закупку и считаете по факту: у каждой модели есть фото из листа подбора и кнопки «−» и «+» у каждого размера. Шубу не из заказа можно отправить на склад или записать в «вернуть поставщику». Если пересчитывать некому, есть кнопка «Принять как заявлено». После проведения программа раскладывает товар: сначала в ждущие отправления, остаток на склад. Отправления, под которые товар не приехал, снова попадают в «не хватает». Отчёт о расхождениях сохраняется.
4. **Склад.** Остатки по моделям и размерам. Размер, который лежит без продаж 14 дней и дольше, подсвечен жёлтым, 30 дней и дольше — красным. Здесь же:
   - пересчёт и ручной приход (ввод или сканер штрихкодов);
   - список «вернуть поставщикам»;
   - журнал операций.

Каждый загруженный лист подбора сохраняется в истории: сколько каких артикулов заказали в этот день. Эта история понадобится для будущей аналитики (закупка на несколько дней вперёд, залежавшийся товар).

## Как читается артикул

`A04-LM9-Ser-1900-3XL`: павильон `A04`, модель `A04-LM9-Ser-1900`, размер `3XL`. Размером считается последняя часть, если она похожа на размер (`42`, `50`, `S`–`6XL`). Разбивку по павильонам можно выключить в настройках.

Артикулы сравниваются по правилам (каждое можно выключить в «Настройках»):

- русские и английские буквы-двойники одинаковы: `АВ-12` (русские) = `AB-12` (английские);
- нули в начале не учитываются: `00123` = `123`;
- пробелы, дефисы, точки и слэши не учитываются: `AB-123` = `AB 123` = `AB123`;
- большие и маленькие буквы не различаются.

## Где хранятся данные

- Если открыть страницу по ссылке claude.ai, данные хранятся вместе со страницей и видны на любом вашем устройстве.
- Если открыть файл `index.html` с компьютера, данные хранятся в этом браузере.

Формат 1С `.mxl` не читается. В 1С сохраните таблицу как Excel (`.xlsx`).
