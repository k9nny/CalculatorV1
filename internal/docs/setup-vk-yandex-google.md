## 2. ВКонтакте — автопостинг машин

ВК публикует посты с фото только от имени администратора группы — нужно приложение VK ID (один раз).

1. Откройте **id.vk.com/about/business/go** → «Создать приложение» (если просят — подтвердите данные и дождитесь одобрения).
2. Тип — веб (сайт). Название `ANDO AUTO`, базовый домен `andoauto.ru`.
3. **Доверенный redirect URL:** `https://andoauto.ru/api/vk/callback`
4. В разделе доступов включите «Стена» и «Фотографии».
5. Скопируйте **ID приложения**.
6. Админка → «Настройки» → «ВКонтакте» → вставить ID → «Подключить ВК» → войти в ВК от аккаунта-администратора группы.
7. Появится страница «ВКонтакте подключён». Дальше каждая новая машина публикуется в группе сама; у старых — кнопка «Опубликовать в ВК».

Если на id.vk.com меню выглядит иначе — скриншот, подскажу.

## 4. Яндекс Вебмастер и Google Search Console

Подтверждение — TXT-записью в REG.RU (там же, где A-записи andoauto.ru): «Добавить запись» → тип **TXT** → имя **@** → значение из кабинета.

**Яндекс Вебмастер** (webmaster.yandex.ru):
1. «Добавить сайт» → `https://andoauto.ru`
2. Способ подтверждения «DNS-запись» → значение вида `yandex-verification: …` → TXT в REG.RU → через 10–30 минут «Проверить».
3. «Индексирование» → «Файлы Sitemap» → `https://andoauto.ru/sitemap.xml`
4. «Информация о сайте» → «Региональность» → Москва.
5. «Индексирование» → «Переобход страниц» → главная, `/cars/`, три страницы услуг.

**Google Search Console** (search.google.com/search-console):
1. «Добавить ресурс» → **«Доменный ресурс»** → `andoauto.ru`
2. Значение `google-site-verification=…` → TXT в REG.RU → «Подтвердить».
3. «Файлы Sitemap» → `sitemap.xml`.

Коды подтверждения — не пароли, их можно присылать.
