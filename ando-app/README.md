# ANDO AUTO — мини-приложение для Telegram и MAX

Каталог машин с пробегом, которые ANDO AUTO выкупила, подготовила в своём автосервисе и продаёт.
Одно приложение работает в Telegram, в MAX и как обычный сайт.

## Что умеет первая версия

- **Каталог**: поиск по марке и модели, быстрые фильтры («Цена ниже рынка», «До 1,5 млн», «Автомат», «Кроссоверы»),
  полные фильтры (марка, цена, год, пробег, коробка, привод, топливо, кузов), сортировка.
- **Карточка машины**: галерея фото, цена и метка «Хорошая / Отличная цена» относительно рыночной оценки,
  характеристики как на Дроме и Авто.ру (двигатель, коробка, привод, владельцы по ПТС, ПТС, VIN частично скрыт),
  блок «Что сделали в нашем сервисе», описание, кнопка «Поделиться».
- **Заявки**: «Записаться на осмотр», «Узнать оптовую цену» для перекупов, «Продать авто» — выкуп у частных владельцев
  (марка, модель, год, пробег, состояние, желаемая цена). Заявка сразу приходит менеджеру в Telegram.
- **Избранное** — сохраняется на устройстве.
- **Ссылка на конкретную машину**: `startapp=car_101` открывает её карточку — для автопостинга в каналы.
- Тема и кнопка «Назад» — родные для Telegram; в MAX и в браузере — по теме телефона.

Объявления сейчас **демонстрационные** (`"demo": true`) — пока они есть, в каталоге видна плашка «Демо-объявления».

## Структура

```
ando-app/
  public/              приложение (статичные файлы)
    index.html
    config.js          настройки: телефон, ник менеджера, ссылки
    platform.js        слой над Telegram WebApp и MAX Bridge
    app.js             каталог, карточка, фильтры, заявки
    styles.css
    data/cars.json     каталог машин
    privacy.html       ШАБЛОН политики персональных данных — впишите реквизиты
  server/
    server.js          раздаёт приложение, принимает заявки, шлёт их в Telegram
    initdata.js        проверка подписи Telegram и MAX
    leads.js           проверка полей заявки и текст сообщения менеджеру
  test/                тесты сервера: npm test
  .env.example         переменные окружения сервера
```

Зависимостей нет: нужен только Node.js 18 или новее.

## Запуск на своём компьютере

```bash
cd ando-app
npm test                        # 18 тестов: сервер, бот, разбор объявлений
cp .env.example .env            # заполните токены и id чатов
node --env-file=.env server/server.js
# откройте http://localhost:8080
```

Без токенов сервер тоже работает: заявки пишутся в `data-private/leads.jsonl` (эта папка не попадает в git).

## Как добавить машину — через бота

Владимир или Андрей присылают боту в Telegram объявление: фото (можно альбомом, до 15) и текст в свободной форме —
или пересылают готовый пост. Бот разбирает текст на поля и показывает превью:

```
Kia Rio 2019, 1.6 АКПП 123 л.с.
Пробег 74 000 км
Цена 1 390 000
2 владельца, ПТС оригинал, белый седан
- Замена масла и фильтров
- Новые колодки
Торг
```

Бот понимает марки по-русски и по-английски («Тойота Камри», «Toyota Camry»), цены вида «1 390 000», «1,39 млн»,
«1390 тыс», пробег «74 тыс км», объём, мощность, КПП, привод, кузов, цвет, владельцев, ПТС, VIN (скрывает часть),
город, «Торг» и «Обмен». Строки со «-» или «✅» и строки про замену и ремонт попадают в «Что сделали в нашем сервисе».

Если что-то распознано не так — отправьте строку «поле значение»: `цена 1 350 000`, `пробег 80 тыс`, `модель Rio X`,
`рынок 1 480 000` (рыночная оценка для метки «Хорошая цена»), `описание …`. Ещё фото — просто пришлите.
Кнопка «Опубликовать» сохраняет фото в `public/img/cars/`, добавляет машину в `public/data/cars.json` — она сразу
видна в приложении — и присылает ссылку на машину и готовый текст поста для каналов.

Команды: `/list` — машины в каталоге, `/reserve 101` — бронь, `/sold 101` — продана (скрыта), `/available 101` —
снова в продаже, `/price 101 1350000` — новая цена, `/cleardemo` — убрать демо-объявления, `/cancel` — удалить черновик.

Добавлять машины могут только id из `ADMIN_IDS`; остальным бот отвечает приветствием и ссылкой на каталог.
Бот работает внутри того же сервера (`server/bot.js`), отдельный адрес для вебхука не нужен.

На сервере `public/data/cars.json` и `public/img/cars/` — живые данные: при обновлении кода из git их не перезаписывайте
(или храните каталог вне репозитория: переменная `CARS_FILE`).

## Как добавить машину вручную

Откройте `public/data/cars.json` и добавьте объект в список `cars`. Удалите демо-объявления (`"demo": true`).

| Поле | Пример | Что это |
|---|---|---|
| `id` | `"215"` | номер объявления, уникальный; по нему работает ссылка `car_215` |
| `status` | `"available"` | `available` — в продаже, `reserved` — забронирована, `sold` — продана (скрыта) |
| `publishedAt` | `"2026-11-02"` | дата публикации, для сортировки «Сначала новые» |
| `make`, `model` | `"Kia"`, `"Rio"` | марка и модель |
| `generation`, `trim` | `"IV"`, `"Comfort"` | поколение и комплектация (необязательно) |
| `year` | `2019` | год выпуска |
| `price` | `1390000` | цена, ₽ |
| `marketPrice` | `1480000` | рыночная оценка, ₽ (например, по оценке Дрома). Дешевле на 7% и больше — «Отличная цена», дешевле рынка — «Хорошая цена». Необязательно |
| `mileage` | `74000` | пробег, км |
| `engine` | `{ "volume": 1.6, "power": 123, "fuel": "Бензин" }` | объём, л.с., топливо: Бензин, Дизель, Гибрид, Электро, Газ/бензин |
| `transmission` | `"Автомат"` | Автомат, Робот, Вариатор, Механика |
| `drive` | `"Передний"` | Передний, Задний, Полный |
| `body` | `"Седан"` | Седан, Хэтчбек, Лифтбек, Универсал, Кроссовер, Внедорожник, Минивэн, Купе, Пикап |
| `color`, `wheel` | `"Белый"`, `"Левый"` | цвет и руль |
| `owners`, `pts` | `2`, `"Оригинал"` | владельцев по ПТС; ПТС: Оригинал, Дубликат, Электронный |
| `vin` | `"Z94C2****K*****21"` | VIN — публикуйте частично скрытым |
| `city` | `"[город]"` | город (необязательно) |
| `photos` | `["img/cars/215-1.jpg"]` | фото: положите файлы в `public/img/cars/`; без фото показывается силуэт |
| `serviceDone` | `["Замена масла и фильтров"]` | что сделали в автосервисе — главный довод доверия |
| `description` | `"…"` | описание |
| `tags` | `["Торг", "Обмен"]` | метки на карточке |

## Подключение к Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot` — получите токен, впишите его в `.env` как `TELEGRAM_BOT_TOKEN`.
2. `/newapp` — создайте мини-приложение для этого бота: адрес — ваш сервер (`https://…`), короткое имя, например `catalog`.
   Ссылка на приложение будет `https://t.me/<бот>/catalog` — впишите её в `config.js` → `telegramAppLink`.
3. Кнопка в меню бота: `/mybots` → бот → Bot Settings → Menu Button → адрес приложения.
4. Владимир и Андрей пишут боту `/start` и узнают свои id (например, у @userinfobot): id тех, кто добавляет машины, — в `.env` → `ADMIN_IDS`, ссылку из шага 2 — в `APP_LINK`.
5. Менеджер (Андрей) пишет боту `/start`, узнаёт свой id (например, у @userinfobot) — id в `.env` → `MANAGER_CHAT_IDS`.
   Можно несколько через запятую или id общего чата, куда добавлен бот.

Ссылка на машину для поста в канале: `https://t.me/<бот>/catalog?startapp=car_101`.

## Подключение к MAX

1. Зарегистрируйтесь на платформе «MAX для партнёров» и пройдите верификацию организации — по открытым
   источникам это доступно юрлицам и ИП — резидентам РФ, подтверждение через Госуслуги или банк-партнёр.
2. Создайте бота, получите токен → `.env` → `MAX_BOT_TOKEN` (по нему сервер проверяет заявки из MAX).
3. В настройках бота укажите адрес мини-приложения — тот же сервер. Мини-приложения в MAX открываются только из бота.
4. Ссылку на бота впишите в `config.js` → `maxAppLink`; ссылка на машину: `https://max.ru/<бот>?startapp=car_101`.

Документация MAX: <https://dev.max.ru/docs/webapps/introduction> и <https://dev.max.ru/docs/webapps/bridge>.
Подпись initData у MAX проверяется по той же схеме, что у Telegram (HMAC-SHA256, ключ `WebAppData`).

## Размещение

Приложению нужен адрес с HTTPS. Сервер с заявками (в них телефоны) должен стоять **в России** — 152-ФЗ.
Подойдёт VPS из расчёта (2 ядра, 2 ГБ) и домен `.ru`. Пример с Caddy (сам получает сертификат):

```
auto.example.ru {
    reverse_proxy 127.0.0.1:8080
}
```

В `.env` поставьте `TRUST_PROXY=1`, запуск — `node --env-file=.env server/server.js` (через systemd или pm2).

**Только статика** (например, GitHub Pages): каталог работает, но сервера заявок нет — заявка откроется готовым
сообщением в чате менеджера (`managerTelegram` / `managerMax` в `config.js`), а если они не заданы — приложение
предложит позвонить.

## Безопасность и персональные данные

- Токены ботов — только в `.env` на сервере, никогда в `config.js` и в репозитории.
- Заявки из Telegram и MAX проверяются по подписи initData; поддельная подпись — отказ.
  `REQUIRE_INIT_DATA=1` — принимать заявки только из мессенджеров.
- Название и цену машины в заявке сервер берёт из каталога, а не из запроса.
- Не больше 6 заявок с одного адреса за 10 минут.
- В формах есть согласие на обработку персональных данных; `privacy.html` — шаблон, впишите реквизиты.
